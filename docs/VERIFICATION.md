# 本地验证记录

验证日期：2026-10-05。环境：Windows、Python 3.13.5、Node 24.19.0、Microsoft Edge。

## 已通过

- 后端 `unittest`：10 个测试方法全部通过，包含多组四则运算和非法输入子用例。
- 实际 HTTP API：成功计算、错误响应、历史读写、指定删除、搜索分页、CORS、健康检查。
- Edge 浏览器：按钮输入、Enter 计算、优先级、括号、小数、负数、错误提示。
- 浏览器刷新后读取数据库历史；按条删除后通过 API 确认对应记录已删除。
- 前端搜索、历史复用、分页、删除最后一页最后一条记录后返回有效页。
- 390px 手机布局没有横向溢出，运行过程没有 JavaScript 页面异常。
- 实际停止后端进程后，前端仍可访问和输入，但无法产生新的计算结果。
- 实际重新启动服务后，原数据库记录仍存在。
- Windows 重复启动会识别已运行服务；停止脚本按 PID 和创建时间确认进程身份并停止进程树。
- Compose YAML 可以解析，部署 ZIP 完整性检查通过，打包内容不含虚拟环境、数据库和真实 `.env`。

浏览器检查只删除自身创建的测试记录，不删除用户已有历史。截图保存在 `docs/screenshots`。

## 2026-10-06 扩展功能验证

- 后端 15 个测试方法全部通过，覆盖旧数据库迁移、收藏持久化、搜索与收藏交集、CSV 跨页导出、编码、引号及空结果。
- 真实浏览器下载 CSV：12 条匹配记录分两页展示，导出仍包含全部 12 条；仅收藏时只导出匹配收藏，空结果导出表头。
- 浏览器模拟时钟验证 07:00 和 19:00 自动切换，手动主题不受时间变化影响，刷新后保留模式。
- 收藏刷新后保留；取消收藏后从收藏筛选列表移除；网络错误不会伪造收藏成功或 CSV 文件。
- 浏览器禁止 LocalStorage 时，主题仍可手动切换。
- 深色桌面与 390px 手机布局已检查，无横向溢出和 JavaScript 页面异常。
- 本地旧库的两条原有历史仍保留，自动增加收藏字段。
- 新增主题及收藏演示截图 17–19；CSV 下载文件供验证使用，保存在 `.runtime`。
